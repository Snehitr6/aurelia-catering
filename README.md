# 🍽️ Aurelia Catering Website

A modern, responsive catering website UI built with **React.js, Vite, and Tailwind CSS**. The website is designed to provide a premium catering experience with elegant visuals, smooth animations, responsive layouts, and interactive sections.

## ✨ Features

* Responsive navigation bar
* Mobile hamburger menu
* Premium hero section
* About Us section
* Catering services section
* Interactive service cards
* Service details modal
* Featured menu / food categories
* Why Choose Us section
* Food gallery
* Customer testimonials
* Contact / event booking form
* Responsive footer
* Mobile call button
* Smooth scrolling
* Hidden browser scrollbar
* Hover effects and subtle animations

## 🛠️ Technologies Used

* React.js
* Vite
* Tailwind CSS
* JavaScript (ES6+)
* Lucide React Icons

## 📱 Responsive Design

The website has been optimized for different screen sizes and includes:

* Mobile-first layouts
* Responsive navigation
* Stacked service cards on mobile
* Responsive images
* Flexible typography
* Consistent spacing
* Desktop multi-column layouts
* Touch-friendly buttons

## 🎨 UI Design

The design uses a premium catering-inspired visual style with:

* Warm brown and beige color palette
* Elegant typography
* Large food imagery
* Minimal borders
* Smooth transitions
* Professional spacing and alignment
* Modern card layouts

## 🔘 Interactive Features

The website includes functional interactions such as:

* Mobile menu toggle
* Navigation scrolling
* Service card selection
* Service details modal
* Event booking navigation
* Menu navigation
* Gallery navigation
* Mobile phone call button
* Hover animations
